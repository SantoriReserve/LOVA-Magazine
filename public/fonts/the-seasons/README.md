# The Seasons — LOVA Wordmark Font

**STATUS: The Seasons is NOT installed in this project.**

Until you add it, the wordmark uses Cormorant Garamond as a temporary
high-contrast editorial serif fallback.

## Add your licensed font

1. Export / download **The Seasons** from Canva or My Creative Land (web license).
2. Place the file here:

```
public/fonts/the-seasons/TheSeasons-Regular.woff2
```

Also accepted:
- `TheSeasons-Regular.otf`
- `TheSeasons-Regular.ttf`

3. Restart the dev server (`npm run dev`).

`@font-face` is already configured in `src/app/globals.css`.
The reusable component is `src/components/Wordmark.tsx`.
